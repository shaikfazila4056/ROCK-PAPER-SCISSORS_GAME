# ✊ Rock, Paper, Scissors Game
A interactive **Rock, Paper, Scissors** game built to practice core programming logic, conditional statements, and random choice generation. Play against the computer, track your scores, and see who comes out on top!

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 🚀 Features

* **Interactive Gameplay:** Play multiple rounds against a computer opponent.
* **Randomized AI:** The computer makes unpredictable moves using random selection logic.
* **Score Tracking:** Keeps a running tally of wins, losses, and ties throughout the session.
* **Input Validation:** Handles invalid user choices gracefully to prevent crashes.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

### 🛠️ Built With

* **Language:** Python *(& frontend- update as needed)*
* **Concepts Used:** Conditional Statements (`if-elif-else`), Loops, Functions, Random Module

-------------------------------------------------------------------------------------------------------------------------------------------------------------------
